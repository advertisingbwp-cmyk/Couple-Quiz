## 2. Compliance Verification

1. **No Runtime Hotlinking**: All files are stored and served locally from `public/prototype/photos/`.
2. **No Scraped Content**: No imagery was scraped, reverse-engineered, or extracted from *Don't Block Me* or any competitor website.
3. **No Copyrighted Trademark Characters**: All assets portray generic lifestyle, food, and activity themes without trademarked characters, sports emblems, or celebrity likenesses.
4. **Isolated Scope**: These assets are strictly consumed by `/design-preview/question` and are excluded from production quiz libraries (`public/quiz/options/` is unchanged).
